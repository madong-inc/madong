## 开源多租户SaaS快速开发框架（4.x稳定版）
我们矢志破除假开源之迷障，倾力构筑一套简约易用、开箱即用的开源SaaS多租户云平台架构。坚守「取之于开源，回馈于开源」的初心，大幅降低企业SaaS业务开发成本，省去大量重复造轮子的冗余工作。让开发者节省工期，专注业务创新，留出更多时间深耕技术、陪伴家人、平衡生活。

## 技术特性
- ✅ 灵活布局系统：轻量化界面、多套主题切换、侧边导览模式，布局参数可视化配置
- ✅ 企业级多租户基座：完整租户隔离、套餐订阅、分库/字段双隔离方案、标准RBAC权限体系
- ✅ 分布式实时消息：WebSocket + Redis 集群推送，多实例稳定互通
- ✅ 安全流量防护：接口限流、访问频次控制、IP黑名单、异常访问拦截
- ✅ 模块化插拔架构：核心基础层+可选业务插件，按需删减，部署轻量化

## 性能表现
⚡ 稳定低延迟：常规2M网络环境接口整体响应 < 300ms，日常请求稳定区间 10~150ms，高并发承载能力优秀

## 功能矩阵
### 一、多租户基础架构
- 租户体系：租户套餐管理、初始化数据模板、分库/字段两种隔离方案
- 权限隔离：租户数据天然隔离，RBAC权限规则适配多租户场景

### 二、组织人事架构
- 用户管理：全平台账号创建、状态管控、登录配置
- 部门管理：树形多级组织，配套部门数据权限过滤
- 岗位管理：自定义职级岗位，适配企业人事审批流程

### 三、系统后台管理
- 精细化权限：菜单、路由、接口、按钮四级权限管控
- 角色管理：批量分配权限，自定义角色数据可见范围
- 全局字典：统一业务枚举字典，前后端共用标准化数据

### 四、监控与安全审计
- 站内通知：全局公告、租户级消息、实时弹窗推送
- 全量操作日志：所有增删改查行为留痕，支持审计追溯
- 登录安全审计：登录地点、设备记录，异地异常登录告警

### 五、设计哲学
大道至简，始终恪守四大开发原则：
1. 代码规范统一，结构清晰易维护
2. 业务CRUD极速开发，大幅缩短交付周期
3. 分层架构低耦合，新增功能无需改动底层核心
4. 前后端开发体验友好，高效落地业务需求

## 环境最低要求
保障生产环境稳定运行，服务器需满足以下条件：
- PHP >= 8.1，必装扩展：mbstring、json、pdo、openssl、redis、pcntl
- MySQL >= 5.7：主业务数据持久存储
- Redis >= 4.0：缓存、分布式锁、消息队列依赖
- Git >= 2.x：代码拉取、版本更新
- Composer >= 2.x：PHP依赖管理
